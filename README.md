# RingTrue

RingTrue tests whether a rented GPU is running the model you paid for.

Traders used to drop a coin on the counter and listen, because a fake one sounded wrong. Renting an anonymous GPU has the same problem: a response arrives, and nothing in it says which model produced it. RingTrue is being built to give buyers on decentralized compute networks a way to check, starting with [Nosana](https://nosana.com).

## Status

Early work, and nothing here is ready to use yet. Code and measurements will land in this repo as runs on real hosts finish.
